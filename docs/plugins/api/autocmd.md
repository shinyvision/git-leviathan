### `LeviathanAutocmdOpts`

Autocmd options.

- `callback` (`fun(event: LeviathanAutocmdEvent)`; required) - Event callback. Receives a typed payload table.
- `group` (`integer`; optional) - Optional autocmd group handle returned by `leviathan.autocmd.group`.
- `once` (`boolean`; optional) - When true, auto-removes the autocmd after its first fire.
- `pattern` (`string`; optional) - Glob pattern matched against a payload string field.
- `debounce_ms` (`integer`; optional) - Coalesce rapid fires within this many host-clock milliseconds.
- `priority` (`integer`; optional) - Higher priority runs first; ties fall back to declaration order.

### `LeviathanAutocmdGroupOpts`

- `clear` (`boolean`; optional) - When true, removes any prior autocmds in the group before returning the handle.

## Functions

### `leviathan.autocmd.group(name, opts)`

Create or fetch an autocmd group handle. Pass `{ clear = true }` to remove any prior autocmds in the group before returning the handle.

**Since:** `1.0`
**Stability:** `stable` (v1)

**Parameters:**
- `name` (`string`; required) - Group name; the same string maps to the same handle for the lifetime of the plugin generation.
- `opts` (`LeviathanAutocmdGroupOpts`; optional) - Group creation options.

**Returns:**
- `integer` - Stable group handle to pass into `leviathan.autocmd.create`.

### `leviathan.autocmd.create(event, opts)`

Register an autocmd for a single typed event.

**Since:** `1.0`
**Stability:** `stable` (v1)

**Parameters:**
- `event` (`string|string[]`; required) - Canonical event name, alias, or array of names.
- `opts` (`LeviathanAutocmdOpts`; required) - Autocmd options including the callback.

### `leviathan.autocmd.clear(group)`

Remove every autocmd registered against a group handle.

**Since:** `1.0`
**Stability:** `stable` (v1)

**Parameters:**
- `group` (`integer`; required) - Group handle returned by `leviathan.autocmd.group`.
