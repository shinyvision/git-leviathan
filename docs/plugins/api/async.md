### `leviathan.async.spawn(body, on_complete)`

Spawn a host-managed worker thread running a Lua body. Returns a handle with `:cancel()`.

**Capabilities:** `async:spawn`

**Since:** `1.0`
**Stability:** `stable` (v1)

**Parameters:**
- `body` (`fun(ctx: LeviathanJobContext): any`; required) - Worker body. Runs on a background thread on a fresh Lua state. Result must be JSON-serialisable.
- `on_complete` (`fun(ok: boolean, value: any)|nil`; optional) - Optional main-thread callback invoked when the worker finishes.

**Returns:**
- `LeviathanJobHandle` - Job handle with `:cancel()` and `:id()`.
