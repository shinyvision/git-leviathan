### `LeviathanKeymapSummary`

- `context` (`string`; required) - Activation context.
- `key` (`string`; required) - Rendered chord (vim-style).
- `command` (`string`; required) - Command the keymap dispatches to.
- `plugin_id` (`string`; required) - Owning plugin id; `<host>` for built-ins, `<user>` for user-config rows.
- `source` (`string`; required) - One of `built-in`, `user`, `plugin`.
- `status` (`string`; required) - One of `active`, `conflict_lost`.
- `description` (`string`; required) - Description text supplied at registration.
- `conflict_with` (`LeviathanKeymapConflictRef|nil`; optional) - When `status == conflict_lost`, points to the winning binding.

### `LeviathanKeymapConflictRef`

Reference to the winning binding for a conflict-lost keymap row.

- `plugin_id` (`string`; required) - Winning binding's plugin id.
- `source` (`string`; required) - Winning binding's source tier.

## Functions

### `leviathan.keymap.set(context, key, command, opts)`

Bind a key chord to a registered command in a context.

**Parameters:**
- `context` (`string`; required) - Activation context (`global`, `repository`, `repository.graph`, `tab_bar`, etc.).
- `key` (`string`; required) - Vim-style key sequence (e.g. `gl`, `<C-r>`, `<leader>gh`).
- `command` (`string`; required) - Command name resolved by the host command registry at dispatch time.
- `opts` (`LeviathanKeymapOpts`; optional) - Keymap options (description, args).

### `leviathan.keymap.del(context, key)`

Remove a previously-registered keymap owned by the calling plugin generation.

**Parameters:**
- `context` (`string`; required) - Activation context the keymap was bound under.
- `key` (`string`; required) - Vim-style key sequence.

### `leviathan.keymap.list()`

List every registered keymap (built-in, user, plugin) including conflict losers.

**Returns:**
- `LeviathanKeymapSummary[]` - Array of keymap summaries with conflict status.
