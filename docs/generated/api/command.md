### `LeviathanCommandSpec`

Descriptor accepted by `leviathan.command.create`.

- `title` (`string`; optional) - Human-friendly palette title; defaults to the command name.
- `description` (`string`; optional) - Long-form description shown in the palette and devtools.
- `context` (`string`; optional) - Activation context name; defaults to `global`.
- `args` (`LeviathanCommandArg[]`; optional) - Argument schema validated at invocation time.
- `destructive` (`boolean`; optional) - When true, the palette filters this command behind a destructive-actions toggle.
- `capabilities` (`string[]`; optional) - Capability names the dispatcher checks at invocation time.
- `run` (`fun(args: table)`; required) - Body of the command; the host runs it inside a coroutine.

### `LeviathanCommandArg`

One entry in a command's `args` schema.

- `name` (`string`; required) - Arg key in the args table.
- `type` (`string`; required) - One of `string`, `boolean`, `integer`, `number`, or `enum:a,b,c`.
- `required` (`boolean`; optional) - Defaults to false. Required args without a default reject the invocation.
- `default` (`LeviathanJson`; optional) - Default value used when the caller omits the arg.
- `doc` (`string`; optional) - Documentation surfaced in the palette and devtools.

## Functions

### `leviathan.command.create(name, spec)`

Register a typed user command in the host registry.

**Parameters:**
- `name` (`string`; required) - Command identifier; unique per plugin.
- `spec` (`LeviathanCommandSpec`; required) - Command descriptor including title, args, run.

### `leviathan.command.invoke(name, args)`

Invoke a registered command by name through the host dispatcher.

**Parameters:**
- `name` (`string`; required) - Command name to invoke.
- `args` (`table|nil`; optional) - Argument table; validated against the command's arg schema.

**Returns:**
- `boolean` - True when dispatch succeeded; false on validation/capability/run failure.

### `leviathan.command.list()`

List every registered command (host + plugin) as descriptor tables.

**Returns:**
- `LeviathanCommandSummary[]` - Array of command summaries.
