### `LeviathanRuntimePathEntry`

- `plugin` (`string`; required) - Plugin id this entry contributes modules for.
- `kind` (`string`; required) - "own" for the calling plugin, "dependency" otherwise.
- `root` (`string`; required) - Absolute filesystem path to the contributing `lua/<plugin>/` directory.

## Functions

### `leviathan.runtime.path()`

Ordered runtime path entries the host will search for `require("plugin_id.module")`.

**Returns:**
- `LeviathanRuntimePathEntry[]` - Entries in search order: own first, then declared dependencies.

### `leviathan.runtime.find(module)`

Resolve a module name against the runtime path without loading it.

**Parameters:**
- `module` (`string`; required) - Module name (e.g. "plugin_id.foo").

**Returns:**
- `LeviathanRuntimeMatch|nil` - Match info or nil when not found / name is invalid.

### `leviathan.runtime.module_graph()`

**Returns:**
- `LeviathanRuntimeModuleGraphEntry[]` - One entry per plugin contributing cached modules.
